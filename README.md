# 얼굴토기 프로젝트

게임과 영상·박물관 참고자료를 분리해 보관합니다.

**[웹에서 게임 열기](https://choi-seungpyo.github.io/face-pottery-workshop/)** · 휴대폰·태블릿 세로/가로와 PC를 지원합니다. GitHub 검사와 배포 기록은 [진행 기록](game/PROGRESS.md)에서 확인할 수 있습니다.

- **game/**: 게임 전체 프로젝트. `game/게임실행.cmd`로 실행합니다.
- **04_목록/**: 영상 제작자가 제공한 캐릭터·유물·공간 참고 원본. 그대로 보존합니다.
- **reference/video/**: 제공받은 영상 원본. 게임 실행본에는 포함하지 않습니다.

게임 개발·검사는 `game/` 안에서 실행합니다. 자세한 방법은 [게임 안내](game/README.md), 현재 작업 상태는 [진행 기록](game/PROGRESS.md)에 있습니다.

```powershell
cd D:\togi\game
npm run dev
```

완성 실행본 주소는 이전과 같은 `http://127.0.0.1:4174/`입니다. 폴더 이동으로 브라우저의 저장 작품을 초기화하지 않습니다. 루트에는 게임과 별도의 참고자료 폴더를 추가해도 됩니다.
