# 작은 흙 공방 프로토타입

캐릭터들과 토기를 빚고, 얼굴을 새기고, 발굴한 뒤 사진으로 남기는 웹게임이다. 현재 플레이에 사용하는 소스와 에셋, 바로 실행할 수 있는 `dist`를 보관한다.

## 게임 열기

웹 배포 주소: **[작은 흙 공방](https://choi-seungpyo.github.io/face-pottery-workshop/)**. `main`에 push하면 GitHub Actions가 빌드와 자동 검사를 거친 실행본을 GitHub Pages에 배포한다.

웹사이트와 PC 로컬 주소는 작품 저장 공간이 서로 다르다. PC에서 만든 작품은 기존 로컬 주소에서 계속 볼 수 있다. 유물 편집기는 PC에서 실행하며, 편집한 원본(`content/museum.json`, `asset/runtime/museum/`)을 commit·push하면 다음 웹 배포에 반영된다.

Node.js 22.12 이상이 설치된 Windows에서 **`게임실행.cmd`를 더블클릭**한다. 브라우저에서 [게임](http://127.0.0.1:4174/)이 열린다. 실행만 할 때는 패키지 설치나 빌드가 필요 없다.

터미널에서 실행하려면:

```powershell
cd D:\togi
npm start
```

실행 중에는 같은 주소로 다시 들어가면 된다. 그림·글꼴·소리·모델은 모두 로컬 파일이며, 유물 출처 링크를 열 때만 인터넷이 필요하다. 실행 기록은 Windows 임시 폴더의 `togi-prototype`에 남는다.

## 플레이

1. 몸체를 끌어 빚고 높이·넓이를 조절한다.
2. 입구 옆 **↔ 넓이 / ↕ 높이 손잡이**를 끌어 바로 다듬는다. 조절 막대나 손잡이에 포커스를 둔 상태에서 방향키로도 조절한다. 드래그 한 번은 되돌리기 한 번으로 복구하며, Esc를 누르면 진행 중인 조절을 취소한다.
3. 얼굴의 **구멍 / 선**을 고른다. 구멍과 옆 구멍은 **톡 누르면 작은 기본 구멍**, **직접 그려 닫으면 그 모양의 구멍**으로 바로 뚫린다. 직접 그린 선을 원으로 바꾸지 않으며, 작은 손떨림과 시작점 근처의 작은 틈만 보정한다. 경계에서의 자동 위치 보정도 최대 4px로 제한한다. 넓게 굽은 표면에도 그릴 수 있고, 구멍이 합쳐지며 몸체와 연결이 끊긴 흙 조각은 함께 제거한다. 표면을 벗어나거나 닫히지 않은 선은 안내만 남기고 지운다. 윤곽을 따로 옮기는 조작은 없다. **더 다듬기**는 원할 때만 사용하는 기능이다.
4. 굽기, 상상 발굴, 시루에 얹기와 유물 비교를 거친다.
5. 완성한 작품과 캐릭터들을 1920×1080 PNG로 저장한다.

**앞·비스듬히·옆·위**로 시점을 바꾸고, **돌려 보기** 또는 마우스 오른쪽 끌기로 둘러본다. 휠이나 ＋/− 버튼으로 확대·축소한다. 되돌리기·다시 실행과 키보드 조작, 움직임 줄이기, 음소거를 지원한다.

## 저장

현재 작품과 진행 상태는 브라우저의 `togi-workshop-v2`에 자동 저장한다. 직전 정상 저장본도 복구용으로 보관한다. 이전 작품을 열 때 저장된 원본을 덮어쓰지 않는다. 예전 구멍 안에 떠 있던 흙 조각과 관통 방향은 화면에 표시할 때 보정한다.

저장한 작품을 이어서 보려면 **같은 브라우저와 같은 주소 `http://127.0.0.1:4174/`**를 사용한다. 개발 주소의 4173번 포트는 별도 저장 공간이다. 브라우저의 사이트 데이터를 지우면 저장 작품도 지워질 수 있다.

예전 `face-pottery-v1` 저장 데이터는 건드리지 않는다. 이전 버전 감상 화면과 편집 원본·시안은 프로젝트 정리 시 복구용 ZIP으로 옮겼다: `D:\togi-prototype-backup-20261109-utf8.zip`.

## 화면과 유물 이야기

가로 화면에서는 왼쪽에 작업 도구와 짧은 사용 설명, 오른쪽에 유물 이야기와 작업 설정, 아래에 시점 조작이 놓인다. 1280×720 이상을 기준으로 작업 패널을 스크롤 없이 사용한다. 휴대폰에서는 오른쪽 위 **작업 설정**을 눌러 상세 설정을 연다. 유물 이야기 카드를 누르면 사진과 단계별 이야기를 페이지로 넘겨 볼 수 있다.

**`유물편집.cmd`를 더블클릭**하면 별도 설치 없이 편집 화면이 열린다. 실행 주소는 `http://127.0.0.1:4175/`다.

1. 게임 단계를 고르고 제목·요약·이야기 문단을 수정한다. 요약은 카드에 들어가도록 140자까지 작성한다.
2. 사진을 추가하거나 선택한 사진을 교체하고, 설명·대체 설명·제공자·이용 조건·출처를 기록한다.
3. 단계별 대표 사진과 문단의 **확인된 내용 / 연구자의 해석 / 게임 속 상상** 구분을 정한다.
4. **저장하고 게임에 반영**을 누르고 게임을 새로고침한다. 글·사진 변경은 재빌드가 필요 없다.

원본은 `content/museum.json`, 사진·모델은 `asset/runtime/museum/`에 저장한다. 실행본의 `dist/museum/`에도 동시에 반영한다. 다른 PC로 옮길 때 프로젝트 전체 또는 실행용 `dist` 전체를 복사한다. 직전 저장본은 **직전 저장본 복구**로 되돌릴 수 있다. 사용자의 토기 저장과는 별도다. 추가한 파일은 복구를 위해 원본 폴더에 보관한다.

배경 유물은 **배경 전시 유물 → 모델 추가**에서 GLB를 등록하고 전시 높이·위치·회전·연결할 이야기를 지정한다. 모델의 가장 낮은 지점을 바닥으로 맞추고, 지정한 전시 높이에 맞춰 크기를 조절한다. 뒤쪽 선반에 올리려면 위치의 Y를 선반 높이로 맞춘다. 등록된 모델은 방과 분리되어 로드되며, 누르면 연결된 이야기가 열린다. 모델이 없으면 기존 장식 토기를 표시한다. 실제 유물 모델은 아직 포함하지 않았으며, 제공받은 자료의 출처와 이용 조건은 운영자가 기록한다.

굽기는 **준비 → 가열 → 냉각 → 완성 공개**로 이어지는 약 14초의 체험 연출이다. 불빛·불티·열기 소리·카메라·재질 변화가 함께 동작한다. 유물 이야기를 열면 연출도 멈추고, **연출 건너뛰기**로 즉시 완성할 수 있다. 움직임 줄이기 설정에서는 카메라 움직임과 불티를 줄이고 약 4초로 보여준다. 실제 유물의 가마나 소성 과정을 복원한 장면은 아니다.

## 코드 수정과 재빌드

```powershell
npm ci
npm run dev
```

개발 화면은 `http://127.0.0.1:4173/`이다. 수정 후 실행본을 갱신하고 검사하려면:

```powershell
npm run verify
```

빌드는 타입 검사와 이용 문서 복사까지 수행한다. `check:openings`는 구멍의 관통 방향, 넓은 곡면의 그리기, 떨어진 흙 조각 제거와 저장 작품 보존을 검사한다. `npm test`는 임시 포트에서 실제 실행본을 열어 파일 응답과 기본 접근 제한을 확인하며, 추가 패키지 없이도 실행할 수 있다. 서버를 실행 중이었다면 빌드 후 브라우저를 새로고침한다.

`verify`는 빌드와 위 검사, 데스크톱·모바일 조작 검사(`check:ui`)를 한 번에 실행한다. 조작 검사는 PC에 설치된 Microsoft Edge를 사용하며, 검사 전용 주소와 새 브라우저 환경에서 실행하므로 사용자의 작품에 접근하지 않는다. 실패할 때만 `asset/review/`에 화면을 남긴다. 평소에는 수정을 모은 뒤 한 번 실행하고, 실패한 검사만 다시 실행한다. 그림·배치가 달라졌을 때만 핵심 화면을 별도로 살펴본다. Playwright는 개발 검사에만 쓰며 실행본에는 포함되지 않는다.

`check:workshop`는 1280×720·1366×768·1920×1080의 배치, 굽기 단계·일시 정지·건너뛰기, 이야기 페이지, 글·사진·GLB 편집과 복구를 검사한다. 편집 검사는 임시 폴더의 가상 자료만 사용한다. 게임과 편집기는 각각 검사 전용 임시 포트에서 실행하며 실제 작품이나 유물 자료를 덮어쓰지 않는다.

## 남겨 둔 파일

- `game/`: 화면, 조형·그리기·발굴, 저장, 소리와 3D 렌더링 코드.
- `asset/runtime/`: 사용하는 캐릭터 PNG, 장면 GLB, 버튼 SVG, WAV.
- `content/`, `asset/runtime/museum/`: 편집 가능한 유물 이야기와 사진·모델 원본.
- `유물편집.cmd`, `Start-Editor.ps1`, `scripts/museum-editor.*`: 유물 편집 도구. Node.js만으로 실행한다.
- `font/`, `assets/`: 사용하는 글꼴과 이용 문서, 실제 유물 사진과 출처.
- `dist/`: 바로 실행하는 게임과 이용 문서. 재빌드하면 갱신된다.
- `server.mjs`, `Start-Game.ps1`, `게임실행.cmd`: 로컬 실행 도구.
- `scripts/`: 빌드 시 이용 문서 복사와 최소 실행 검사.

TypeScript·Vite·Three.js를 사용한다. 토기 조형은 회전형 곡선 편집이며 점토 물리 해석은 아니다. 유물에서 확인한 특징, 사용법의 추정, 체험용 상상은 화면에서 구분한다. 자료와 이용 조건은 [출처 문서](assets/CREDITS.md)에 보관한다.
