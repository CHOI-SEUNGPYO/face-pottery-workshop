# 내 얼굴토기

어린이 박물관에서 흙의 윤곽과 얼굴을 직접 만들고, 자기 작품을 다시 찾아보는 반응형 웹 체험.

Penpot `UI`의 흐름 00–09와 `UI_실제게임화면_최종시안.md`를 기준으로 구현한다.
캐릭터 원본과 제공된 폰트를 사용한다. 실제 유물의 특징, 사용법에 관한 추정, 게임 속 상상 체험을 구분한다.

개발 계획과 검증 결과는 [PLAN.md](PLAN.md)에 기록한다.

## 실행

Node.js 20 이상과 WebGL을 지원하는 Chrome 또는 Edge가 필요하다.

```powershell
cd D:\togi
node server.mjs
```

브라우저에서 **http://127.0.0.1:4173** 을 연다. 종료는 실행한 터미널에서 Ctrl+C.
Windows에서는 `Start-Game.ps1`을 PowerShell로 실행해 서버와 브라우저를 함께 열 수도 있다. 이 경우 서버는 백그라운드에서 실행된다. 다른 포트가 필요하면 실행 전에 `$env:PORT='4174'`처럼 지정한다.

폰트·캐릭터·사진·3D 라이브러리는 모두 로컬 파일이다. 실행 중 인터넷 연결이나 추가 패키지 설치가 필요하지 않다. ‘출토 자료 보기’ 외부 링크만 인터넷을 사용한다. `index.html`을 파일로 직접 열면 ES 모듈을 불러올 수 없으므로 위 서버를 사용한다.

## 조작

1. **몸체**: 정면을 고정하고 옆 윤곽을 좌우·상하로 옮겨 높이마다 굵기를 바꾼다. 같은 높이의 둘레는 원형으로 유지한다. 맨 위·아래를 잡으면 전체 높이가 바뀐다. 가장자리 밖 48px 이내에서도 잡을 수 있다. ‘돌리기’에서 360도로 살펴보고 ‘다듬기’를 누르면 정면으로 돌아온다. 이전의 비대칭 작품은 실제 편집을 시작할 때 원형 단면으로 정리되며 되돌리기로 복구할 수 있다.
2. **정수리**: 윗면에 구멍의 윤곽을 이어 그린다. 그린 안쪽을 비우고, 윤곽을 따라 낮게 올라온 입구와 두께를 만든다. 단순한 폐곡선은 그린 좌표를 그대로 사용하고, 교차하는 별은 바깥 윤곽을 구한다. 열린 끝은 자동으로 잇는다. 흙 밖으로 벗어난 선은 임의로 축소하지 않고 다시 그리도록 안내한다. 한 번 누르기나 면적이 없는 선은 구멍을 만들지 않는다.
3. **얼굴**: ‘파기’ 하나로 톡 눌러 작은 구멍, 닫힌 테두리로 큰 구멍, 열린 선으로 홈을 만든다. ‘밀어 뚫기’는 귀 같은 옆 구멍을 만들며, 누르거나 테두리를 그리면 주변 흙이 바깥으로 둥글게 올라온다. 눈·입의 일반 구멍은 돌출하지 않는다. 구멍에는 내부까지 이어지는 벽 두께가 있다. 돌리기로 360도 회전하며 얼굴 수를 자유롭게 정한다. 두 면·세 면 안내선은 선택 사항이다.
4. **확인**: 필요하면 몸체·정수리·얼굴 편집으로 돌아간다. ↶ 또는 Ctrl+Z는 현재 단계에서 한 작업만 취소한다. 다른 단계에서 만든 모양은 유지하며, 해당 단계의 기록이 없으면 버튼을 비활성화한다. 앞 단계에 다시 가면 그 단계의 편집 기록을 사용할 수 있다.
5. **굽기**: ‘과정 보기’를 누르면 건조·가열·냉각을 짧게 표현한다.
6. **발굴**: 흙을 넓게 쓸어 만든 토기와 시루를 찾는다. 아래 ‘붓질’ 버튼으로도 조금씩 걷어 낼 수 있다.
7. **시루**: 토기를 직접 끌어 얹거나 ‘시루에 얹기’ 버튼을 누른다.
8. **비교·감상**: 실물 사진과 비교하고 완성 화면에서 자기 작품을 돌려 본다. 이미지 저장 기능은 포함하지 않았다.

작품 한 개와 진행 단계가 브라우저에 자동 저장된다. 같은 주소·브라우저에서 ‘이어 만들기’로 복원한다. 새 작품은 확인 후 이전 저장을 대체한다. 여러 방문객의 작품을 모으는 기능은 없다.

## 고증과 구현 범위

- 실제 유물 사진과 근거는 [assets/CREDITS.md](assets/CREDITS.md)에 정리했다. 세 얼굴, 윗부분의 구멍, 얼굴 사이 구멍, 시루의 제거된 바닥과 두 뿔 모양 손잡이를 안내한다.
- 시루 위에 토기를 얹어 사용했다는 설명은 **추정**으로 표시했다. 굽는 시간·온도·발굴 행동은 실제 제작법이나 조사 과정을 복원한 것이 아니다.
- 3D 토기는 실측 복원물이 아닌 **변형 가능한 체험용 모델**이다. 한 덩어리의 몸체와 높이를 다듬는다. 흙을 따로 붙이거나 떼어 내는 작업, 완전한 점토 물리 시뮬레이션은 없다.
- 몸체는 맨 위까지 같은 윤곽으로 이어지며 고정된 머리 덮개가 없다. 제공된 `artifact.png`에서 보이는 위가 넓고 아래가 좁아지는 비례와 짧은 입구를 참고했다. 새 작품의 기본 비례만 참고한 것으로, 얼굴 조각까지 실측 복원한 모델은 아니다.
- 몸체 생성에는 Three.js r180의 `LatheGeometry`(MIT)를 사용한다. 출처와 적용 범위는 [vendor/SOURCES.md](vendor/SOURCES.md)에 기록했다. 다듬은 실제 반지름을 `profile`에 저장하며, 다음 조작·회전·구멍·되돌리기도 같은 윤곽을 사용한다. 이전 저장은 읽을 수 있지만 기존 끝부분 보정이 제거되어 표시 윤곽은 달라질 수 있다. 맨 위가 닫히는 점과 최소 두께·최대 크기 한계는 유지한다.
- 윤곽을 잡으면 접촉한 부근만 변한다. 수직 이동은 윤곽의 순서가 뒤집히지 않도록 계산하며, 움직인 주변의 접힘만 부드럽게 잇는다. 손을 떼거나 같은 곳을 다시 잡았다고 전체 윤곽을 평활화하지 않는다. 물레의 힘 전달을 참고한 조형 근사이며 흙 부피·벽 두께·중력을 보존하는 물리 시뮬레이션은 아니다.
- 수직 조형은 각 흙 구간의 실제 높이인 `profileLevels`를 저장한다. 위에서 누르면 꼭대기도 내려오고 바닥은 유지된다. 기존 최소 높이 0.65 및 초기 위치의 45% 이동 제한은 없앴다. 바닥을 통과하지 않도록 전체 두께 0.22와 화면 범위는 남기며, 바닥에 가까워져 이동이 멈추면 안내한다. 기존 저장은 높이 좌표를 자동으로 계산해 읽고 새 작품으로 초기화하지 않는다.
- 얼굴과 정수리 구멍은 마스크로 표면을 비우고, 실제 테두리 벽 메시와 어두운 내부를 함께 표시한다. 정수리 입구는 그린 모양을 따라 외벽·윗테두리·내벽이 이어진다. 별이나 비대칭 입구는 창작 표현이며, 해당 모양이 실제 유물에 있다는 뜻은 아니다. 조각한 선과 구멍은 굽기·발굴 뒤에도 동일하게 유지된다.
- ‘밀어 뚫기’는 구멍 둘레의 외피·내벽을 추가하는 체험용 표현이며 실제 제작법을 확인했다는 뜻이 아니다. 완전한 점토 변형 시뮬레이션은 아니며, 매우 오목하고 복잡한 테두리에서는 돌출부가 겹칠 수 있다.
- 옆 돌출 구멍은 몸체 기울기를 따라 바깥쪽·위쪽으로 올라오며 내부로 이어진다. 작은 원과 끝이 조금 벌어진 윤곽도 닫아 가운데를 비우고, 열린 반원·선은 홈으로 남긴다. 기존 저장의 파기 선에도 같은 판정을 적용한다.
- 저장은 최대 120개 얼굴 표현, 몸체·정수리·얼굴 각각 최근 24번 되돌리기를 지원한다. 새로고침하면 작품은 유지되고 되돌리기 기록은 비워진다.
- 브라우저에서 1920×1080, 1280×720, 1024×768, 390×844, 320×568 크기를 확인했다. 작은 화면은 세로 스크롤을 허용한다. 실제 전시 터치스크린의 손가락 감도·GPU 성능·다중 접촉은 현장 검사가 필요하다.

## 수정과 검사

문구·단계별 캐릭터는 `src/content.js`, 레이아웃·폰트·버튼은 `styles.css`, 형태와 질감은 `src/pottery.js`에서 바꾼다.

```powershell
node --test tests/*.test.mjs
```

검사 내용: 조형과 저장 복원, UV 경계를 넘는 구멍, 실행 취소, 완성 후 재편집 시 진행 초기화, 로컬 서버와 자산 제공, 숨김 경로·쓰기 요청 거부.

추가 검사: 실제 포인터 처리 함수에 닫힌 별·교차 별·동그라미를 전달해 윤곽 보존과 가운데 비우기를 확인한다. 정수리의 위치 보존과 영역 밖 입력 거부, 몸체의 구멍 판정과 입구 메시를 함께 사용한 별 중심/끝 관통, 테두리 두께, 원형 단면·상하 이동·회전 모드·저장과 되돌리기를 검사한다. 높이 0.65–1.45 및 120회 누르기에서도 몸체가 꼭대기까지 이어지고 바닥이 닫혀 있는지 검사한다. `tests/visual.html`은 같은 렌더러로 둥근 입구·별 입구·위쪽을 좁히고 늘인 몸체를 비교하는 개발용 검사 화면이다.

`tests/raised-visual.html`에서 일반 구멍과 돌출 구멍의 정면·측면을 비교할 수 있다. `tests/workshop.html`은 4175 검사 서버에서만 검사 작품을 준비한다. 단계별 반복 취소, 앞 단계 재방문, 저장 복원, 파기 통합 동작과 돌출부 관통은 자동 검사에 포함한다.

`tests/local-clay-visual.html`은 아래쪽 접힘을 같은 입력으로 당긴 이전 계산과 수정 후 결과를 비교한다. `tests/workshop.html`의 접힌 윤곽 검사 작품으로 실제 드래그·회전·취소·저장을 확인할 수 있다.

`tests/continuous-press-visual.html`은 긴 목을 가진 같은 작품을 위에서 계속 누른 결과를 비교한다. `tests/workshop.html`의 상단 누르기 검사 작품으로 이전 높이 제한을 넘는 누르기·재조작·저장 복원을 확인할 수 있다.

## Git 흐름

- 공개 게임: https://choi-seungpyo.github.io/face-pottery-workshop/
- 저장소: https://github.com/CHOI-SEUNGPYO/face-pottery-workshop
- `.github/workflows/pages.yml`에서 main·develop·PR의 기존 검사를 실행한다. 검사를 통과한 main만 GitHub Pages로 자동 배포한다. 필요하면 Actions의 ‘Run workflow’로 main을 다시 배포한다.
- 배포 파일은 index.html, styles.css, src, vendor, assets, asset, font다. 로컬 실행 도구·테스트·기획 문서는 접속 페이지에 포함하지 않는다. 공개 사이트의 작품 저장은 해당 브라우저에 보관되며 localhost의 저장 작품과 별개다.

- `main`: 확인한 실행 버전
- `develop`: 기능 통합
- `feature/*`: 단계별 구현 후 develop으로 병합
- `release/*`: 전체 검증 후 main과 develop으로 병합, 버전 태그
- origin은 위 공개 저장소에 연결한다. 로컬 작성자는 Codex다.
