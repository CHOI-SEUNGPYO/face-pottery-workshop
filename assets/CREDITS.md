# 자료와 출처

- `artifact.png`: Penpot UI 파일에 사용된 문화재청 2019년 소월리 출토 자료 사진을 내보낸 파일. 얼굴 장식 토기와 시루를 함께 놓은 사진이며, 결합 사용은 추정이다. 공개 전시·배포 권한의 최종 확인은 운영자가 진행한다.
- [원문: 전통문화포털에 수록된 문화재청 자료](https://www.kculture.or.kr/brd/board/399/L/menu/498?bbIdx=11513&brdType=R). 설명의 사실/추정 구분은 이 자료의 본문을 2026-11-07에 확인한 내용을 따른다. 사진의 공개 이용 허가를 새로 확인했다는 뜻은 아니다.
- `asset/runtime/characters`: 압이·독이·경산이는 사용자가 확인한 원본형 에셋을 수정 없이 복사했다. 소월이는 기존 제공 에셋을 사용한다. 원래 캐릭터의 권리 관계를 변경하지 않는다.
- `asset/runtime/models`: 프로젝트에서 제작한 작업실·발굴 공간·시루·받침이다. 외부 모델을 내려받아 사용하지 않았다. Blender 편집 원본과 생성 스크립트는 프로젝트 정리 전 복구용 ZIP에 보관했다.
- `asset/runtime/audio`: 프로젝트에서 직접 합성한 배경음 2개와 효과음 5개다. 역사적 음악의 재현으로 표시하지 않는다.
- `asset/runtime/ui`: 직접 작성한 버튼 SVG 2개다. 도구 아이콘은 `game/icons.ts`에 있으며, 텍스트는 브라우저에서 표시한다.
- 글꼴: 제공된 Cafe24 Ssurround v2.0, 나눔스퀘어라운드, Pretendard. 제공된 Pretendard·Cafe24 이용 문서는 `font`와 배포물의 `licenses`에 보관한다. 나눔스퀘어라운드는 제공 폴더에 별도 이용 문서가 없어 운영자가 원 배포처의 이용 조건을 함께 보관해야 한다.
- Three.js r180, three-mesh-bvh, polygon-clipping, robust-predicates, splaytree의 이용 문서는 배포물의 `licenses`에 포함한다.
- 게임 속 토기·흙 질감은 동적으로 생성하는 체험용 시각 표현이다. 실제 유물 사진과 구분한다.
- `asset/runtime/museum/artifact.png`는 위 `assets/artifact.png`의 편집용 복사본이다. 추가하는 사진·모델의 설명, 출처, 제공자와 이용 조건은 유물 편집기에서 운영자가 관리한다. 초기 상태에는 새로 확보한 외부 유물 모델이 포함되어 있지 않다.
- 굽기의 공간·불빛·불티·열기 소리는 코드로 만든 체험 연출이다. 특정 유물의 가마·온도·소성 과정을 복원한 것으로 제시하지 않는다.

## 입구 표현

문화재청 발표는 낮게 돌출된 원통형 구멍을 설명하지만, 막힌 윗면을 손가락으로 눌러 여는 동작이나 제작 순서는 확인되지 않는다. 게임에서는 열린 기본 형태에서 입구를 다듬도록 한다.
