# 영상 참고 자료

사용자가 제공한 `영상 1차.mp4`를 `asset/` 바로 아래에서 이 폴더로 옮겼다. 원본은 삭제하거나 변환하지 않았다.

- 1280×720, 24 fps, 약 71.25초, 18,017,467바이트
- 확인한 내용: 박물관 실내와 전시물, 경산이·독이·압이의 입체감, 장면별 재질·조명·카메라 이동
- 게임의 얼굴토기 제작 장면은 영상에 아직 없다. 게임 화면의 구성과 조작은 별도로 제작한다.
- 이 영상은 로컬 참고 자료다. Git과 실행본 `dist/`에는 포함하지 않는다.
- 게임에 사용하는 파생 재질·캐릭터의 제작 정보는 `asset/source/README.md`에 기록한다.
