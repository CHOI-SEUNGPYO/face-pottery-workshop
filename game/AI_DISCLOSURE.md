# AI 제작 표시와 공식 박물관 링크

확인·반영: 2026-11-16. 대상은 이 폴더의 웹게임과 게임에서 저장하는 PNG다. 참고 원본인 영상·사진 파일을 수정하거나 원격 웹사이트에 배포한 작업은 아니다.

## 적용 범위

현재 게임은 미리 제작한 이미지·3D 모델·소리를 읽어 실행한다. 플레이 중 생성형 AI 서비스에 요청하지 않으며, 플레이어가 토기의 형상과 구멍을 직접 조절한다. 개발 과정에서는 생성형 AI로 일부 배경·재질·캐릭터 이미지를 생성·편집했고, 코드와 3D 모델 제작에도 AI의 도움을 받았다.

과학기술정보통신부의 「인공지능 투명성 확보 가이드라인」은 AI 제품·서비스를 제공하는 사업자와 이미 만들어진 AI 결과물을 콘텐츠 제작에 사용하는 이용자를 구분한다. 후자의 단순 활용은 해당 가이드라인에서 투명성 의무 대상이 아니라고 설명한다(PDF 6–7쪽, 본문 2–3쪽). 따라서 **AI를 사용해 개발한 모든 게임에 동일한 표시 의무가 발생한다고 전제하지 않는다.** 현재 구현은 이 단순 활용 예시에 가까우며, 이용자가 제작 방식을 알 수 있도록 표시 방법을 참고해 자발적으로 안내한다. 운영 주체나 서비스에 AI 생성 기능이 추가되면 적용 범위를 다시 검토해야 한다.

## 표시 위치와 의미

- 시작 화면: 시작·이어하기 버튼 앞에 「AI(인공지능) 활용 제작 / 일부 배경·캐릭터는 AI로 생성·편집했어요」를 표시한다.
- 플레이 화면: 왼쪽 위 제목 아래에 「AI 생성물 포함」을 유지한다. 도움말에서 상세 제작 안내를 열 수 있다.
- 제작·출처 안내: AI 활용 범위, 사용자가 직접 만드는 작품, 실제 유물 사진, 사진·영상 기반 3D 재현을 구분한다. 재현 모델은 실측 스캔으로 소개하지 않는다.
- 사진 꾸미기: HTML 안내와 이미지 아래의 「AI(인공지능) 생성·편집 콘텐츠 포함」 표시를 함께 보여 준다.
- PNG 저장: 같은 문구와 사용자 직접 조형 안내를 불투명한 하단 영역에 그려 1920×1080 이미지의 픽셀에 포함한다. 스티커보다 나중에 그리므로 스티커 이동·삭제·되돌리기로 가려지거나 없어지지 않는다. 별도의 동의 체크나 저장소 초기화는 추가하지 않았다.

실제 유물 사진에는 AI 생성 워터마크를 덧씌우지 않는다. 사진의 제공자·출처는 기존 유물 이야기와 `assets/CREDITS.md`에서 계속 관리한다. AI 표시는 저작권·이용 허락을 대신하지 않는다.

## 확인한 공식 근거

- [인공지능기본법 제31조 제2항](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031810729): 확인한 현행 법률은 2026-07-21 시행, 법률 제21311호다.
- [같은 법 시행령 제23조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lspttninfSeq=198075&chrClsCd=010202): 확인한 현행 시행령은 2026-08-20 시행, 대통령령 제36580호다. 사전 안내 방법, 사람이 인식하는 표시 또는 기계 판독 표시, 이용자 특성에 따른 명확성을 규정한다. 이 프로젝트의 글자 크기·표시 면적을 법정 수치라고 소개하지 않는다.
- [과학기술정보통신부 인공지능 투명성 확보 가이드라인](https://www.msit.go.kr/bbs/view.do?sCode=user&nttSeqNo=3148988&bbsSeqNo=81&mId=102&mPid=100), 첨부본 2026-01-26: 적용 대상(PDF 6–7쪽), 창작물 감상을 고려한 표시(PDF 9쪽), 외부로 저장하는 결과물 표시(PDF 11쪽), 이미지 표시 예시(PDF 20쪽)를 확인했다. 이 기록은 구현 근거이며 개별 서비스의 적법성을 보증하는 법률 검토서는 아니다.

## 경산시립박물관

[경산시립박물관 공식 홈페이지](https://www.gbgs.go.kr/museum/main.do)의 제목과 실제 페이지를 확인했다. 시작 화면·도움말·제작 안내·유물 이야기에서 새 탭으로 연다. 작품 저장 이미지는 같은 공식 사이트 주소를 글자로 남긴다. 사진별 자료 출처 링크도 별도로 유지한다.

## 회귀 검사

`check:workshop`에서 작은 휴대폰 세로·가로, 태블릿, PC의 시작 안내·버튼·링크 배치와 단계별 표시를 확인한다. `check:journey`는 스티커가 하단으로 이동하거나 삭제돼도 표시 영역의 픽셀이 유지되고, 다운로드한 PNG에도 같은 픽셀이 남는지 검사한다. 검사 전용 주소와 새 브라우저 환경을 사용해 실제 사용자의 저장 작품에 접근하지 않는다.
