# 작은 흙 공방의 디자인 원칙

2026-11-17. 첫 화면·공방·가마·발굴·전시·예시 감상·내 작품 촬영에 같은 원칙을 적용한다. 원래 저장 작품, 실제 유물 자료와 캐릭터의 색·선·비율은 유지한다.

## 조사한 공식 사례

- [Smithsonian 3D 뷰어 안내](https://3d.si.edu/how-use-3d-viewer): 배경·바닥·조명을 형태와 표면을 살펴보는 별도 도구로 제공한다. 실제 모델 화면은 접근 확인 단계로 열지 못했으며 공식 사용 안내를 근거로 삼았다.
- [Rijksmuseum, The Milkmaid](https://www.rijksmuseum.nl/en/collection/object/The-Milkmaid--42dd0e658c2979aec8e144d2357c55c0): 작품 감상 영역을 크게 두고 확대·전체 맞춤과 정보를 구분한다. 작품 크기와 정보 위계에 참고했다.
- [V&A Collections](https://www.vam.ac.uk/collections): 작품·이야기·전시 여부의 관계를 명시한다. 창작 예시와 실제 유물의 성격을 명확하게 구분한다.
- [국립중앙박물관 사유의 방 전시 설명](https://www.museum.go.kr/MUSEUM/contents/M0701040000.do?arcId=17991&catCustomType=post&catId=93&cp=80&schM=view&sv=): 유물의 크기와 형태에 맞춘 조명, 감상에 집중하는 주변 공간과 설명의 위계를 참고했다. 실제 전시 공간 사례이며 게임 화면을 박물관의 실제 전시실 재현이라고 표현하지 않는다.

## 게임에 적용할 판단

아래는 공식 규격이 아니라 위 사례를 참고한 이 게임의 디자인 선택이다.

1. **작품이 먼저 보인다.** 토기·케이스를 감상 영역에 크게 맞추고 얼굴을 읽을 수 있는 시점과 부드러운 빛을 쓴다. 주변 공간은 시선을 작품으로 모으는 역할을 한다.
2. **놓인 자리를 만든다.** 유리 케이스와 얇고 단단한 받침, 접촉 그림자를 유지한다. 강한 목재 무늬와 벽·바닥의 큰 색 대비를 줄이고 차분한 석재·흙빛 재질을 사용한다.
3. **한 화면에 하나의 주된 행동을 둔다.** 감상에서는 회전, 촬영에서는 사진 저장을 중심으로 둔다. 스티커·다시 찍기·닫기는 크기와 강조를 낮춘다. 실제 터치 영역은 44px 이상 유지한다.
4. **버튼과 설명이 작품을 덮지 않는다.** 넓은 화면에서는 감상 영역과 설명/도구를 나란히, 좁은 화면에서는 위아래로 둔다. 닫기와 완료는 일정한 위치에 두고 화면 높이가 짧을 때도 접근할 수 있어야 한다.
5. **재질과 출처를 혼동하지 않는다.** 예시는 개발자가 게임에서 빚은 작품임을 작게 안내한다. 실제 유물·AI 재현·사용자 창작의 기존 구분과 촬영물의 AI 활용 표시는 유지한다.
6. **장식 때문에 무거워지지 않는다.** 기존 3D 렌더러와 실행 재질을 재사용하고 조작할 때만 감상 화면을 그린다. 닫을 때 임시 자원을 해제한다.

## 확인 기준

- 회전 전후 저장 작품의 좌표·구멍·선·진행 상태가 같음
- 촬영에는 본인 작품과 케이스만 나오고 예시 유물은 제외됨
- 유리 5면과 받침이 모든 회전에서 토기를 감싸며 사진의 AI 안내 영역을 침범하지 않음
- PC·태블릿·휴대폰 세로/가로에서 제목·닫기·저장 버튼이 겹치지 않음
- 실제 회전·스티커 조작·PNG 저장·닫기·이어 만들기가 유지됨

## 전체 장면 적용 · 2026-11-17

- 공방은 석재 바닥, 회녹색 작업대, 흰 회벽, 목재 테두리로 면을 구분했다. 선반의 어두운 목재 뒷판을 회벽으로 바꾸어 유물의 윤곽과 간격을 읽기 쉽게 했다.
- 야외는 경계 밖 나무 군집을 56개에서 16개로 줄이고 먼 풍경에만 옅은 대기감을 준다. 가마·발굴 지면·보존 작업대가 중심이고 기존 석담·길·준비 공간은 유지한다.
- 전시실은 석재 바닥과 받침, 낮은 채도의 회녹색 전시장 뒷판을 사용한다. 뒤 선반의 작은 유물은 24개에서 16개로 줄여 간격을 확보하고, 큰 항아리도 두 점으로 정리했다. 실제 박물관의 진열 형식을 참고하되 공간과 색은 게임의 감상 목적에 맞춘 해석이다.
- 버튼은 금빛 주 행동 / 밝은 보조 행동으로 나누고 과장된 입체 그림자를 줄였다. 안내·작업 도구·하단 이동 버튼의 기존 안전 영역과 44px 터치 목표를 유지한다.
- 휴대폰 첫 화면은 짧은 목표 설명을 위에, 시작·이어 만들기·예시 감상을 아래에 배치한다. 가운데 작업대를 실제로 볼 수 있도록 3D 구도를 남은 공간에 맞춘다.
- 예시 감상은 좌우 회전과 상하 시점 조절을 함께 지원한다. 화면 크기에 맞는 미리보기 픽셀만 사용하며 원래 저장 작품의 방향·모양은 바꾸지 않는다.
- 바닥의 개별 나무 판자 메시를 줄이면서 공방·전시실 구조 GLB 합계는 11.87MB에서 0.62MB로 줄었다(십진 MB, 두 파일 기준). 경량화는 재질만 바꾸는 대신 실제 에셋을 다시 제작한 결과다.

장면 비교 이미지는 `node scripts/review-scenes.mjs`로 별도 브라우저에서 생성한다. 이 검사는 실제 사용자 저장 공간에 접근하지 않는다. 기능과 배치 검증은 기존 `npm run verify`로 유지한다.
