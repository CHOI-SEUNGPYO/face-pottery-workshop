# 박물관 제공 인트로·엔딩 크레딧

`intro-ending-credits.pptx`는 사용자가 제공한 `경산시립박물관 협업_인트로 엔딩 크레딧.pptx`를 변경 없이 보관한 사본이다.

게임은 슬라이드 1·3의 영남대학교 인문사회디지털융합인재양성사업단·경산시립박물관 로고, 슬라이드 2의 2026년 지원 과정명을 사용한다. 영상용 ‘100% AI 영상물·Higgsfield’ 문구는 게임 제작 방식에 맞게 바꿨다. 원본 발표 자료는 실행본에 포함하지 않는다.

로고는 PPTX에 삽입된 PNG 그대로 `game/asset/runtime/credits/`에 있다. 코드와 화면 구성은 `game/src/museum-presentation.ts`·`.css`에서 편집한다. 실제 유물 사진과 개별 제공자·출처는 `game/content/museum.json`에서 관리한다.
